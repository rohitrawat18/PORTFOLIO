# Rohit Rawat — Portfolio

A responsive developer portfolio built with React 19, Vite 8, and Tailwind CSS 4.

## Highlights
- Editorial dark UI with electric mint accents, subtle grid/noise texture, and responsive layout
- Hero introduction, about section, featured projects, skills, process, and contact section
- Project cards link to public GitHub repositories
- Responsive mobile navigation and copy-email interaction
- Accessible labels, semantic sections, reduced-motion support, and SEO metadata

## Tech
React · Vite · Tailwind CSS · React Icons · CSS

## Run locally
```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
npm run preview
```

## Deployment
Import this repository into Vercel or Netlify. Use the default Vite build command `npm run build` and output directory `dist`.
